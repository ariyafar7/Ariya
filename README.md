# Michael the Microbe

An 8-bit "elgoog" concept Doodle for World IBS Day (19 April): dive through the gut with Michael the Microbe and see how stress affects it. University prototype (MEDN2002/DESN3010, UNSW). General health information, not medical advice.

- **Play online:** https://ariyafar7.github.io/Ariya/ (once GitHub Pages is switched on, see below)
- **Download an offline copy:** [michael-the-microbe.zip](https://github.com/ariyafar7/Ariya/raw/claude/stress-gut-microbiota-game-s60adh/michael-the-microbe.zip). Unzip it and open `index.html` in any browser, keeping `soundtrack.mp3` in the same folder.

## Files

- `docs/` is the playable web version (served by GitHub Pages).
- `index.html` is the source as published to Claude.
- `RUNTHROUGH.md` walks through every screen.

## Switching on the web link

In this repository on GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, then pick branch `claude/stress-gut-microbiota-game-s60adh` and folder `/docs`, and press **Save**. The game appears at https://ariyafar7.github.io/Ariya/ within a few minutes.
